# 🪵 Ресторан «Лукоморье» — Интерактивное меню

Элегантное электронное меню для заведения с деревянной текстурой, акцентом на озёрно-голубых тонах, поддержкой номеров столиков из URL, адаптацией под гостевой Wi-Fi и мгновенной отправкой заказов в Telegram-группу «заказы».

---

## 📁 Структура проекта

```
lukomorie_menu/
├── photos/                  # Папка с фото блюд
│   ├── meat/                # Мясные блюда (например: Стейк_Рибай.jpg)
│   ├── fish/                # Рыбные блюда (например: Форель_на_гриле.jpg)
│   └── other/               # Прочие блюда (например: Овощи_гриль.jpg)
├── static/
│   ├── css/
│   │   └── style.css        # Стили (дерево + глубокий голубой, плавные анимации)
│   ├── js/
│   │   └── app.js           # Логика корзины, столов и заказов
│   └── index.html           # Главная страница меню
├── config.json              # Настройки (Telegram Bot токен, ID группы, Wi-Fi)
├── bot_service.py           # Сервис форматирования и отправки сообщений в Telegram
├── server.py                # Бэкенд на FastAPI
└── start.bat                # Быстрый запуск в 1 клик для Windows
```

---

## ⚡ Как запустить

1. Запустите файл `start.bat` (двойным кликом) или выполните в консоли:
   ```bash
   py -3 server.py
   ```
2. Откройте сайт в браузере:
   - **Со столиком № 1:** `http://localhost:8000/?1`
   - **Со столиком № 2:** `http://localhost:8000/?2`
   - **Со столиком № 5:** `http://localhost:8000/?5`
   - Без столика: `http://localhost:8000/` (сайт предупредит гостя, что заказ возможен только при указании столика).

---

## 🛎️ Столики и QR-коды для гостей

В ссылке после знака вопроса указывается номер столика:
- `http://ваш_домен_или_ip/?1` — столик №1
- `http://ваш_домен_или_ip/?2` — столик №2
- `http://ваш_домен_или_ip/?table=3` — также поддерживается

**Для заведения:**
Создайте QR-коды для каждого столика с соответствующей ссылкой (например через любой генератор QR-кодов) и наклейте на столы. Когда гость сканирует QR-код телефоном, столик определяется автоматически!

## 📸 Как добавлять блюда

Вам **не нужно писать код или заполнять базу данных**:
1. Просто положите фотографию блюда в нужную папку:
   - `photos/meat/` — для мясных блюд
   - `photos/fish/` — для рыбных блюд
   - `photos/other/` — для салатов, гарниров, десертов
2. Назовите файл именем блюда, например:
   - `Стейк_Рибай_на_углях.jpg`
   - `Форель_запеченная_с_лимоном.png`
   - `Хачапури_по_аджарски.webp`
3. **На самом сайте имя блюда не отображается** (согласно вашему пожеланию — только аппетитное фото, выбор количества `[-] [1] [+]` и кнопка `В заказ`).
4. При заказе сайт автоматически расшифрует название из имени файла и передаст на кухню в Telegram точное и красивое наименование блюда!

## ✈️ Настройка Telegram-бота для группы «заказы»

1. Откройте Telegram и напишите боту **[@BotFather](https://t.me/BotFather)**:
   - Отправьте команду `/newbot`
   - Задайте имя (например: `Лукоморье Заказы`) и username (например: `lukomorie_order_bot`)
   - Скопируйте полученный **токен бота** (например: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

2. Создайте группу в Telegram с названием **`заказы`**:
   - Добавьте в группу вашего созданного бота.
   - Сделайте бота администратором группы (чтобы он мог отправлять сообщения).

3. Узнайте `Chat ID` вашей группы:
   - Добавьте в группу бота **[@RawDataBot](https://t.me/RawDataBot)** или перешлите любое сообщение из группы в бот **[@getmyid_bot](https://t.me/getmyid_bot)**.
   - ID группы обычно начинается со знака минус, например: `-1001987654321`.

4. Откройте файл `config.json` в папке проекта и вставьте ваши данные:
   ```json
   {
       "telegram_bot_token": "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ",
       "telegram_chat_id": "-1001987654321",
       "wifi_names": [
           "Лукоморие",
           "Лукоморие_5G"
       ],
       "enforce_wifi_modal": true,
       "port": 8000,
       "host": "0.0.0.0"
   }
   ```
5. Перезапустите сервер. Теперь каждый заказ мгновенно приходит в вашу группу Telegram!

## 📶 Ограничение по Wi-Fi («Лукоморие» и «Лукоморие_5G»)

> **Важная техническая особенность:** Согласно стандартам безопасности W3C, современные браузеры на телефонах (Chrome, Safari, iOS, Android) не позволяют веб-страницам напрямую считывать имя Wi-Fi сети устройства из соображений конфиденциальности.

### Как это правильно реализовать в заведении:

1. **Локальный сервер внутри сети заведения (Рекомендуемый стандарт ресторанов):**
   - Компьютер с сервером (ноутбук, кассовый ПК или компактный Raspberry Pi) подключен к Wi-Fi роутеру «Лукоморие».
   - В адресной строке или QR-коде указывается локальный IP (например: `http://192.168.1.50:8000/?1`) или настроенный локальный домен на роутере (например: `http://menu.lukomorie/?1`).
   - **Результат:** Человек, который не подключен к сети «Лукоморие» или «Лукоморие_5G», физически **не сможет открыть сайт**, так как локальная сеть закрыта от внешнего интернета!
2. **Встроенное предупреждение на сайте:**
   - В шапке сайта всегда горит индикатор сети «Лукоморие».
   - Если гость кликает на него, открывается модальное окно с напоминанием подключиться к «Лукоморие» или «Лукоморие_5G».
